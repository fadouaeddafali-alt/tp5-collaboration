StudentManager — Gestion des étudiants

  1. Présentation du projet

StudentManager est une application web frontend permettant de consulter et de gérer une liste d'étudiants.

Ce projet est réalisé dans le cadre du **TP5 : Travail collaboratif avec Git et GitHub**, du module Développement Web Full Stack et DevOps.

L'objectif principal est de mettre en pratique le travail collaboratif à travers Git, GitHub, les branches, les commits, les Pull Requests et la résolution des conflits.

 2. Objectifs du projet

- Afficher une liste d'étudiants.
- Rechercher un étudiant par nom, prénom ou matricule.
- Filtrer les étudiants selon leur filière.
- Afficher le nombre total d'étudiants.
- Afficher le nombre de résultats après chaque recherche ou filtrage.
- Apprendre à travailler en équipe avec Git et GitHub.

 3. Technologies utilisées

- HTML5: structure de la page web.
- CSS3: mise en forme et design de l'application.
- JavaScript: gestion des données, recherche, filtrage et compteurs.
- Git: gestion des versions du projet.
- GitHub: hébergement et collaboration en ligne.
- Visual Studio Code: environnement de développement.

 5. Fonctionnalités

 5.1 Affichage des étudiants
L'application affiche les informations des étudiants dans un tableau : matricule, nom, prénom, âge et filière.

 5.2 Recherche
L'utilisateur peut rechercher un étudiant à partir de son nom, de son prénom ou de son matricule.

 5.3 Filtrage
L'utilisateur peut filtrer les étudiants selon leur filière :
- Génie Informatique
- Cybersecurity
- Développement Informatique

 5.4 Compteurs
L'application affiche le nombre total d'étudiants et le nombre de résultats correspondant aux critères sélectionnés.

 6. Installation et lancement

git clone https://github.com/fadouaeddafali-alt/tp5-collaboration.git


2. Entrer dans le dossier :


cd tp5-collaboration


3. Ouvrir le projet dans Visual Studio Code :


code .


4. Ouvrir le fichier `index.html` avec Live Server ou directement dans un navigateur.

 7. Travail collaboratif avec Git et GitHub

Le projet utilise trois types de branches :

- main : version stable et finale du projet.
- dev : branche d'intégration du travail des membres.
- feature/ : branches utilisées pour développer les fonctionnalités.

 Organisation du travail

Chaque membre travaille sur une branche personnelle, réalise ses modifications, puis les partage avec le groupe à travers une Pull Request vers la branche `dev`.


 8. Gestion des conflits

Dans le cadre du TP5, un conflit Git est provoqué volontairement lorsque deux membres modifient la même partie d'un fichier.

Le conflit est résolu en analysant les deux versions, en choisissant le contenu final et en supprimant les marqueurs de conflit.


 9. Conclusion

Ce projet nous a permis de découvrir et de pratiquer le développement web collaboratif avec Git et GitHub.

Nous avons appris à créer et utiliser plusieurs branches, à enregistrer et partager nos modifications, à réaliser des Pull Requests, à fusionner les travaux et à résoudre un conflit Git.
